# Techinical Info

## Player Tracking

Player tracking uses the [EarthMC map](https://map.earthmc.net){ target="_blank" } to find players. Squaremap tracks player in the frontend by downloading a file called [players.json](https://map.earthmc.net/tiles/players.json){ target="_blank" }, which contains the coordinates of every player visible on the map, every few seconds. This file contains coordinates and yaw for every player that is visible on the map and is formatted in JSON.
